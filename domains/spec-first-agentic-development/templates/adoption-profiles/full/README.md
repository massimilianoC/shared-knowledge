# SFAD Full Profile

The Full profile is **not a separate starter kit**. It is the Base profile plus the complete SFAD extension layers already maintained in this package. See [the profile guide](../README.md) for the exact composition and promotion sequence.

## Full extension inventory

| Extension | Source | Adds |
| --- | --- | --- |
| Canonical project documentation | [`../../spec-first-methodology/core/`](../../spec-first-methodology/core/) | Vision, architecture, requirements, analysis, milestones, execution tracking, and tool aliases. |
| Operating complements | [`../../agentic-project/`](../../agentic-project/) | Constitution, feature-spec refinement, and session handoff. |
| Stack overlays | [`../../spec-first-methodology/flavors/`](../../spec-first-methodology/flavors/) | Optional stack-specific architecture and UI guidance. |

When these documents become active, migrate the Base roadmap and any accepted feature/decision content into the listed canonical Full locations. Maintain one source of truth per concern.
